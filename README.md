## ⏱️ Recommended Study Pathways

### 🚀 Path A: Fast-Track Revision (2-3 Hours)
1. Study [`docs/00-two-hour-sketchnote.md`](docs/00-two-hour-sketchnote.md) for core visual patterns.
2. Review [`docs/06-coding-challenge-playbook.md`](docs/06-coding-challenge-playbook.md) for code implementation patterns.
3. Test your knowledge using [`docs/07-mock-assessment.md`](docs/07-mock-assessment.md).

### 🎓 Path B: Full Frontier Mastery (12-15 Hours)
1. Methodically work through `docs/01` through `docs/05`, completing all embedded conceptual exercises.
2. Implement the 3 Python code templates in `docs/06`.
3. Complete the mock assessment in `docs/07` under timed conditions (45 minutes).
4. Verify weak areas using the glossary and checklist in `docs/08`.
