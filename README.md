# Master Frontier Engineer Study Plan

A practical, assessment-focused study repository for **Master Frontier Engineering Capstone Assessment — 201 Intermediate**.

This plan covers the requested domains:

- Generative AI and large language models
- Prompt engineering and structured outputs
- Embeddings, vector search, and semantic retrieval
- Retrieval-Augmented Generation (RAG)
- Agentic AI and tool-using workflows
- Enterprise AI architecture and governance
- AI security, privacy, evaluation, observability, and cost control
- AI-assisted coding and code-challenge execution

## Recommended order

1. Read [`docs/00-two-hour-sketchnote.md`](docs/00-two-hour-sketchnote.md) for rapid revision.
2. Review the domain notes in `docs/01` through `docs/06`.
3. Attempt the mock assessment in [`docs/07-mock-assessment.md`](docs/07-mock-assessment.md) without looking at the answer frames.
4. Use the glossary and final checklist for spaced revision.
