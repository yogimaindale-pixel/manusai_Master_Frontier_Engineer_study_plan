# Frontier Engineer Interview Package

This directory contains the expanded, textbook-style preparation package for the **Master Frontier Engineer — Build track** interview.

Start with [`MASTER_STUDY_GUIDE.md`](./MASTER_STUDY_GUIDE.md), then use the question bank, case studies, hands-on labs, learning plans, and last-minute revision sheet.

The package distinguishes verified candidate context from public technical references and proposed practice designs. It does not claim to reproduce confidential interview questions or predict the exact panel.
